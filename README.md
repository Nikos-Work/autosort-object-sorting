# AutoSort — Automated Object Sorting System

An Arduino-based mechatronics project developed as part of a university course, focused on automated object sorting using sensor measurements and a motorized mechanism.

## Overview

AutoSort is a prototype designed to identify object properties and automate the sorting process. The system combines sensor integration, embedded programming, and motor control to distinguish objects based on properties such as transparency, moisture, and the presence of metal.

## Hardware

- **Microcontroller:** Arduino
- **Sensors:** Infrared (IR), inductive proximity, and moisture sensors
- **Actuators:** Servo motor and stepper motor
